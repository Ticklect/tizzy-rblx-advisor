# Game-design brain

## Decompose the game into building blocks

For concept/design questions, map the experience across these dimensions:
1. **Core fantasy** — what impossible/desirable role or scenario is the player buying into?
2. **Primary verb / core loop** — what do they repeatedly do? Can it be described simply?
3. **Unique mechanic / meaningful twist** — what changes player decisions rather than merely skin/theme?
4. **Acquisition/RNG structure** — where does randomness occur? Before or after acquisition? Spawn table, roll, stock refresh, etc.?
5. **Level design** — linear, radial, hub, safe zones, pressure valves, verticality; how does it affect pacing?
6. **Tension** — threat, time pressure, scarcity, PvP, risk/reward, anticipation and release.
7. **Progression** — faster, stronger, richer, more capable, new area, new strategy.
8. **Long-term collection/identity** — pets, treasures, blocks, builds, index, cosmetics, mastery.
9. **Socialization** — is it more fun with friends? Does another human create unsolved situations?
10. **Clippability/community** — what moments would a player or creator want to show?
11. **Accessibility** — especially mobile/console. Can the central mechanic remain easy to perform?

## Building-block innovation

The corpus repeatedly treats Roblox hits as derivative combinations of proven building blocks. Originality is not "invent a genre nobody understands." The better question is: **which proven blocks remain, and where are you making a meaningful change?**

Do not fetishize a numeric "20%" rule as universal truth. Treat it as a public Tizzy heuristic: modest success may come from changing a few important blocks; breakout scale usually needs several meaningful innovations plus execution.

## Depth over complexity

Depth = simple rules creating many outcomes/decisions. Complexity = many rules/systems the player must learn.

Depth sources:
- PvP / unpredictable humans
- building / expressive layouts
- stealing / defending / risk
- trading / social economy
- random events/RNG
- collections with meaningful choices
- skill/mastery
- roleplay/creative expression
- map geometry that changes encounters

Ask whether the strategy becomes solved in minutes. If yes, add uncertainty/interaction/depth, not five disconnected menus.

## Tension/release

Look for a loop of anticipation and relief. Examples of mechanisms: threat chasing player, time pressure, safe zones, inventory at risk, scarce stock, PvP interception, uncertain roll. Level design can compress or extend tension.

## First-session game design

The title promise should become real quickly. Lead with the most engaging mechanic. Introduce one major concept at a time. The first 30-90 seconds should create emotional investment, not just tutorial compliance.

## Social flywheel

A recurring corpus claim: games become more viral when the game is materially better with friends. Ask:
- Can friends cooperate?
- compete?
- flex status?
- steal/defend?
- show builds/items?
- create funny/clippable events?

Intentional co-play is also a current Roblox recommendation signal, so social design has both product and distribution implications; verify current docs if making a current algorithm claim.

## Level-design lens

Map geometry changes gameplay. Consider:
- meaningful encounter frequency
- distance to conflict/objective
- sightlines and hiding
- juking/escape routes
- safe-zone placement
- center-space events
- travel downtime
- how easy it is to find other players

A bigger map can make a PvP/social game worse by diluting interactions.

## Game-design answer shape

Fantasy -> loop -> proven blocks -> missing depth/tension/social layer -> meaningful twist -> mobile friction -> MVP test -> metric/behavior to watch.
