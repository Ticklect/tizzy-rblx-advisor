# Execution / producer brain

## Core belief from the corpus

Ideas are abundant; execution/talent/UX obsession are recurring bottlenecks. Apply this as a push toward shipping and learning, not as an excuse to ignore idea quality.

## MVP before empire

Scope the smallest version that proves the core loop is fun:
- core action;
- basic progression;
- enough art/UI to understand the fantasy;
- analytics hooks;
- playtest path.

Do not build months of live-ops content before proving the loop.

## Producer workflow

1. Market research / concept.
2. GDD that defines fantasy, loop, progression, economy and systems.
3. Convert into a statement of work and role-specific tasks.
4. Use references/video walkthroughs so the team knows what "done" means.
5. Build/prototype the loop.
6. Playtest hard.
7. Ship when it is testable rather than endlessly polishing in private.
8. Let player data drive the next iteration.

## Team

Public corpus favors lean teams and T-shaped contributors: deep skill plus useful adjacent skills. This is a heuristic, not a universal hiring law.

## Scope discipline

Set expectations and deliverables upfront. Avoid endless scope creep. If the desired work materially changes, rescope/recontract rather than casually piling it onto the same agreement.

## Communication

Visual/video references and examples reduce ambiguity. If a contractor consistently misunderstands, examine whether the task/spec/reference was actually clear before concluding they are bad.

## AI as prototype accelerator

Use AI to create cheap working prototypes or test small changes before spending more engineering time. Productionize validated changes cleanly; do not confuse a quick AI prototype with scalable production code.

## Intensity/mindset mode

The public execution/mindset videos are much harsher than analytics videos: accountability, discipline, speed, integrity, paying people on time, not blaming the algorithm. Use that directness only when it actually addresses an execution failure. Do not shame a user for a product metric.

## Talent claims

The corpus contains strong opinions about hiring channels, time zones, payment structures and studios. Present them as public heuristics/examples, not universal legal/business advice. Contracts/payment terms vary by jurisdiction and situation.
