# Acquisition, discovery, analytics, and ads brain

## Current-truth rule

Roblox discovery/ads systems change. Verify current official Roblox docs when answering a current factual question. The 2026 corpus is historical evidence of reasoning, not permanent platform truth.

Current official discovery framing (verify before quoting exact details): Recommended for You considers multiple signals around engagement, retention, social interaction and monetization; Roblox distinguishes retrieval from ranking; ranking is based on users coming through Recommended for You, while non-home sources can help generate initial consideration/data. Benchmarks are comparison tools, not direct ranking inputs.

## Funnel

Think as a leak model:
1. Impression / packaging
2. PTR / detail-page conversion
3. First-play bounce
4. First-session quality
5. D1 / early return intent
6. D7 / mid-term depth
7. D28 / long-term durable play
8. Social/co-play
9. Monetization/spend behavior

Do not repair stage 1 when stage 2 is healthy and stage 3 is leaking.

## Metric-to-cause map

**Weak PTR:** title/icon/thumbnail/fantasy comprehension, detail-page presentation, audience fit.

**Good PTR + bad bounce:** packaging is attracting clicks but first minute is failing. Inspect promise mismatch, loading, spawn confusion, tutorial friction, device bugs, immediate lack of core action.

**Weak D1:** FTUE, emotional investment, first-session payoff, early progression, tutorial, whether the player leaves wanting something.

**Good D1 + weak D7:** game can hook once but is consumed/solved too quickly. Inspect content depth, progression, social systems, events, collection, weekly reasons.

**Good D7 + weak D28:** durable identity/mastery/community/live ops/long-term goals are weak.

## Segment before conclusions

Filter by:
- source (Home recommendations vs ads/search/friends/etc.)
- device (mobile/console/desktop)
- cohort/date
- geography/demographic only where legitimate/relevant

A blended tutorial completion or retention average can hide a broken console/mobile flow.

## Ads are not magic distribution

Public corpus pattern: ads are useful for traffic/data/UA, not a substitute for fixing product metrics. "Spend more" without a meaningful product change is usually weak advice.

For current ad budgets/targeting rules/age gates, verify current Roblox docs. Do not hard-code historical numbers like "$16/day" as universal advice.

## Sponsored-ad creative thinking

Before buying traffic:
- clear core fantasy/title;
- readable thumbnail;
- enough creative variants to learn;
- first-minute experience that fulfills the promise.

Test multiple genuinely different creatives. CTR alone can be misleading if the creative overpromises and bounce explodes.

## Hypothesis loop

Metric -> segment -> player behavior -> hypothesis -> smallest change -> experiment/A-B test when possible -> inspect primary metric + guardrails.

Roblox currently supports in-game experiments for onboarding, progression, shop UX/pricing and other changes; verify current availability/metrics when advising.

## Myth handling

When the user repeats Twitter/Discord lore:
1. check official docs;
2. separate documented rule from anecdotal developer observation;
3. explain why both might appear true in specific contexts;
4. do not overclaim causality.
